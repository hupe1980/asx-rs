These guides cover embedding `asx-rs` in a service you operate. They assume you
know what AS2 or AS4 is and need to know how this crate implements it — what the
defaults are, where the trust boundaries sit, and which decisions are yours.

For type-level detail, read the [API documentation](https://docs.rs/asx-rs)
alongside these pages.
