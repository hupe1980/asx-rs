# ns_per_op baseline for `xtask perf-gate --check-baseline`.
#
# Measured on the CI Linux runner, in **release**, with the feature set
# `.github/workflows/ci.yml` invokes the gate with:
#
#   as2,as4,client,server,trace,compression,async-ocsp,interop-strict
#
# Local macOS runs come out faster, but `as2_sign_encrypt` (RSA-2048 sign plus
# encrypt) is load-sensitive: it has been observed between 1.0 ms and 7.0 ms on
# one machine depending on what else was compiling. Measure on a quiet machine,
# or a local failure will be the other work rather than the code.
#
# Only benchmarks this configuration compiles may appear here: an entry with no
# matching measurement is a gate failure, not a skip. The receive-path
# benchmarks are behind `testing`, which is a `compile_error!` in release, so
# they run under a debug `just perf-gate` and are not baselined.
as2_sign_encrypt=2600000.000
as2_mdn_generation=500.000
as4_precheck_markers=640.000
as4_receipt_generation=550.000
